Estruturação semântica de conteúdo

O que aprendemos..

Porque ele é importante?

O HTML estrutura o significado do conteúdo, enquanto o CSS cuida da aparência visual.
Usar tags apenas pela estética (como para negrito ou para itálico) ignora a semântica.
Prefira tags que dão sentido real ao texto (como para forte importância ou para ênfase)
e deixe o estilo por conta do CSS.

Conclusão

Html organiza e dá significado ao conteudo enquanto o CSS cuida da aparência. ortanto, use tags semânticas como e e deixe a estilização para o CSS.
